# Base Trafalgar Junkyards site

A responsive, self-contained static website for Base Trafalgar Junkyards. The existing DTR POB dashboard remains at the repository root; this site lives in its own folder.

## Preview

Open `index.html` in a browser or serve this folder with any static web server.

## Before publishing

- Replace `ADD_YARD_EMAIL_HERE` in `script.js` with the yard's enquiry email to enable email links from the form.
- Add the real address, phone, hours, social profiles, and service details when available. No real location, contact details, stock quantities, prices, or testimonials are currently included.
- The part category cards are enquiry prompts, not live inventory. Yard stock changes; confirm availability directly.

No build step or dependency installation is required.
